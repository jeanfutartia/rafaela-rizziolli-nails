# Rafaela Rizziolli Nails

Landing page da nail designer Rafaela Rizziolli (Piracicaba - SP), desenvolvida pela **N11 Creative System**.

- Tabela de valores em abas (Fibra, Gel, Outros)
- Botões de agendamento pelo WhatsApp com mensagem pronta por serviço
- Galeria de formatos, FAQ, botão flutuante no mobile

## Rodar localmente
Abra o `index.html` no navegador (ou use a extensão Live Server do VS Code).

## Deploy no Render
1. New → **Static Site** → conecte este repositório.
2. Build Command: deixe vazio.
3. Publish Directory: `.`

Ou use o `render.yaml` (Blueprint).
